# Checklist Manual: Autenticacao

- [ ] Cadastro valido cria usuario, perfil, score e token.
- [ ] Cadastro com e-mail repetido exibe erro.
- [ ] Cadastro sem aceitar termos exibe erro.
- [ ] Login valido redireciona para anuncios.
- [ ] Login invalido mostra mensagem generica.
- [ ] Logout encerra sessao.
- [ ] Usuario bloqueado nao consegue fazer login.
- [ ] POST sem CSRF e recusado.
- [ ] A verificacao de e-mail aceita token valido e recusa token expirado/usado.
