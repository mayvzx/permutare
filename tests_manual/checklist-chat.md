# Checklist Manual: Chat

- [ ] Chat fica bloqueado antes do aceite.
- [ ] Chat abre para dono e proponente apos aceite.
- [ ] Usuario externo nao acessa conversa.
- [ ] Mensagem vazia e recusada.
- [ ] Mensagem valida aparece no historico.
- [ ] Mensagens recebidas sao marcadas como lidas ao abrir conversa.
- [ ] Aviso de seguranca aparece no chat.
- [ ] Chat concluido permite consultar historico.
