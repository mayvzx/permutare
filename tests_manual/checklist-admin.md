# Checklist Manual: Admin

- [ ] Admin acessa dashboard.
- [ ] Usuario comum nao acessa `/admin`.
- [ ] Admin lista usuarios.
- [ ] Admin bloqueia e desbloqueia usuario.
- [ ] Admin promove usuario para admin.
- [ ] Admin nao rebaixa a si mesmo.
- [ ] Admin lista e remove anuncios.
- [ ] Admin lista denuncias.
- [ ] Admin marca denuncia em analise.
- [ ] Admin resolve denuncia e pode bloquear usuario denunciado.
- [ ] Admin arquiva denuncia.
