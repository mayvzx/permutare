# Checklist Manual: Anuncios

- [ ] Usuario autenticado cria anuncio valido.
- [ ] Criacao sem campos obrigatorios exibe erro.
- [ ] Upload acima de 2MB e recusado.
- [ ] Upload com extensao invalida e recusado.
- [ ] Usuario edita anuncio proprio.
- [ ] Usuario nao edita anuncio de outra pessoa.
- [ ] Pausar remove anuncio do feed.
- [ ] Reativar recoloca anuncio no feed.
- [ ] Remover faz soft delete.
- [ ] Busca por texto funciona.
- [ ] Filtros por categoria e condicao funcionam.
