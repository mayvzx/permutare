# Checklist Manual: Propostas

- [ ] Usuario envia proposta para anuncio de outra pessoa.
- [ ] Sistema impede proposta no proprio anuncio.
- [ ] Sistema impede proposta pendente duplicada.
- [ ] Dono aceita proposta pendente.
- [ ] Aceite pausa anuncio e rejeita outras propostas pendentes.
- [ ] Dono recusa proposta pendente.
- [ ] Proponente cancela proposta pendente.
- [ ] Propostas enviadas exibem status correto.
- [ ] Propostas recebidas exibem acoes corretas.
